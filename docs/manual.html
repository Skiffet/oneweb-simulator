คู่มือการติดตั้งและใช้งาน

OneWeb Core Network Simulator
Brownien Lab x Satellite NT telecom

1. ความต้องการของระบบ

เครื่อง Server

  • Ubuntu 22.04 / 24.04
  • Node.js v18 ขึ้นไป
  • Python 3.10 ขึ้นไป
  • PostgreSQL 14 ขึ้นไป
  • Nginx

เครื่องที่รัน Expo (เครื่อง Developer)

  • Node.js v18 ขึ้นไป
  • npm หรือ npx
  • อยู่ในเครือข่าย WiFi เดียวกับมือถือ

มือถือ

  • iOS 13 ขึ้นไป หรือ Android 6.0 ขึ้นไป
  • แอป Expo Go (ติดตั้งฟรีจาก App Store / Google Play)

2. การติดตั้ง Expo Go บนมือถือ

iPhone (iOS)

  1. เปิด App Store
  2. ค้นหา "Expo Go"
  3. กด GET เพื่อติดตั้ง
  4. เปิดแอปและกด "Scan QR Code"

Android

  1. เปิด Google Play Store
  2. ค้นหา "Expo Go"
  3. กด ติดตั้ง
  4. เปิดแอปและกด "Scan QR Code"

3. การติดตั้งโปรแกรมบนเครื่อง Server

ทำครั้งแรกครั้งเดียว ไม่ต้องทำซ้ำทุกครั้ง

ขั้นที่ 1 — เข้าสู่ Server ผ่าน SSH

ssh admin@122.155.209.87

รหัสผ่าน: 1qazxsw2

ขั้นที่ 2 — โหลด Code จาก GitHub

cd ~ && git clone https://github.com/Skiffet/oneweb-simulator.git
cd oneweb-simulator
git checkout feature/remove-entry-time

ขั้นที่ 3 — ติดตั้ง Node.js Dependencies

cd ~/oneweb-simulator/server
npm install

สร้างไฟล์ .env ในโฟลเดอร์ server/ ใส่ข้อมูลดังนี้:

DB_HOST=localhost
DB_PORT=5432
DB_NAME=oneweb_db
DB_USER=oneweb_user
DB_PASSWORD=oneweb1234
JWT_SECRET=oneweb-super-secret-key-2024
PORT=3000

ขั้นที่ 4 — ตั้งค่า PostgreSQL

sudo -u postgres psql

พิมพ์คำสั่งต่อไปนี้ใน psql:

CREATE DATABASE oneweb_db;
CREATE USER oneweb_user WITH PASSWORD 'oneweb1234';
GRANT ALL PRIVILEGES ON DATABASE oneweb_db TO oneweb_user;
ALTER USER oneweb_user WITH PASSWORD 'oneweb1234';
\q

ขั้นที่ 5 — ติดตั้ง Python Dependencies

cd ~/oneweb-simulator/backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
pip install "numpy<2.0"

สร้างไฟล์ .env ในโฟลเดอร์ backend/ ใส่ข้อมูลดังนี้:

SPACE_TRACK_USERNAME=wongphithakwanchana@gmail.com
SPACE_TRACK_PASSWORD=1qazxsw23edcvfr4

ขั้นที่ 6 — ตั้งค่า Nginx

sudo apt install nginx -y

สร้างไฟล์ /etc/nginx/sites-available/oneweb ใส่เนื้อหาดังนี้:

server {
    listen 80;
    server_name 122.155.209.87;

    location /api/auth/ {
        proxy_pass http://localhost:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    location /api/ {
        proxy_pass http://localhost:5000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}

แล้วรัน:

sudo ln -s /etc/nginx/sites-available/oneweb /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx

4. การรันระบบ

ทำทุกครั้งที่ต้องการเปิดใช้งาน

บน Server — Terminal 1: รัน Node.js

ssh admin@122.155.209.87
cd ~/oneweb-simulator/server && node index.js

รอจนขึ้น:

OneWeb Auth Server running on port 3000
PostgreSQL connected

บน Server — Terminal 2: รัน Python Flask

ssh admin@122.155.209.87
cd ~/oneweb-simulator/backend && source venv/bin/activate && python3 app.py

รอจนขึ้น:

Running on http://0.0.0.0
Fetching new TLE data from Space-Track...
ต้องรอให้ดึงข้อมูลดาวเทียมเสร็จก่อน (1-2 นาที) จึงจะแสดงผลในแอปได้

บนเครื่อง Developer — รัน Expo

cd ~/oneweb-simulator && npx expo start

จะขึ้น QR Code ในหน้าต่าง Terminal

เชื่อมต่อมือถือ

  1. เปิดแอป Expo Go บนมือถือ
  2. กด "Scan QR Code"
  3. สแกน QR Code ที่ขึ้นใน Terminal
  4. รอแอปโหลด (ครั้งแรกอาจใช้เวลา 1-2 นาที)

5. การใช้งานแอปพลิเคชัน

6. การแก้ปัญหาเบื้องต้น

แอปขึ้น "เชื่อมต่อ server ไม่ได้"

ตรวจสอบว่า Node.js รันอยู่บน server:

lsof -i :3000 | grep LISTEN

แผนที่ไม่แสดงดาวเทียม / หมุนค้าง

Python Flask อาจยังดึงข้อมูลไม่เสร็จ รอ 1-2 นาที แล้วตรวจสอบ:

lsof -i :5000 | grep LISTEN

Port ถูกใช้งานอยู่แล้ว (EADDRINUSE)

kill -9 $(lsof -ti :3000 :5000 2>/dev/null) 2>/dev/null

แล้วรัน Node.js และ Python ใหม่

QR Code สแกนไม่ได้ / แอปโหลดไม่ขึ้น

  • ตรวจสอบว่ามือถือและเครื่อง Developer อยู่ WiFi เดียวกัน
  • ลองกด r ใน Expo Terminal เพื่อ reload
